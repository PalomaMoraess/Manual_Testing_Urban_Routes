# 📋 Testes Manuais - Urban Routes

## 📖 Sobre o projeto

Este projeto foi desenvolvido durante minha formação em Quality Assurance (QA) na TripleTen.

O objetivo foi realizar testes de regressão na aplicação Urban Routes, executando casos de teste previamente definidos, registrando os resultados e documentando os bugs encontrados durante a validação do sistema.

---

## 🎯 Objetivos

- Executar casos de teste de regressão.
- Identificar falhas na aplicação.
- Registrar bugs de forma estruturada.
- Classificar a prioridade dos defeitos encontrados.

---

## 🛠️ Ferramentas utilizadas

- Google Sheets
- Testes Manuais
- Casos de Teste
- Relatórios de Bugs

---

## ✅ Atividades realizadas

- Execução de 24 casos de teste.
- Registro dos resultados (Aprovado/Reprovado).
- Identificação de 8 bugs.
- Elaboração de relatórios de bugs.
- Definição da prioridade dos defeitos encontrados.

---

## 📂 Arquivos do projeto

- Casos de Teste
- Relatórios de Bugs

---

## 📚 Aprendizados

Durante este projeto desenvolvi habilidades importantes para a área de Quality Assurance, como execução de testes manuais, análise de resultados esperados, identificação de defeitos, elaboração de relatórios de bugs e priorização de problemas conforme seu impacto na aplicação.
